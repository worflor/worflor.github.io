# Vendored Data Attribution

`sms-sample.txt` is a small sample (first 400 messages, in original order, with exact
duplicates removed) drawn from the **UCI SMS Spam Collection** dataset, made available
by the UCI Machine Learning Repository under the **CC BY 4.0** license.

- Source: https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

This sample is vendored solely as a small, real-world text fixture for tests in this
repository (e.g. exercising Unicode density, punctuation, and casing found in genuine
human SMS messages). It is not redistributed as a complete dataset and is not used for
any purpose beyond local testing.
